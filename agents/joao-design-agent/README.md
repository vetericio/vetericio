# João Design Agent

Pacote declarativo do agente João, versão 1.0.0. A configuração é portátil e não concede credenciais, instala integrações nem autoriza deploy por si só.

As dez skills estão em `skills/`. Os fluxos operacionais estão em `workflows/`. O teste Playwright usa `tests/visual.config.ts` quando o projeto-alvo fornecer uma URL e seus próprios scripts.

Integrações pendentes nesta entrega: checkout/repositório ORICSE, GitHub instalado para esta conta, Figma, Canva, Playwright no projeto-alvo, Lighthouse, axe-core e destino de deploy autorizado.
